# market (the phone app)

The Flutter app for Android and iOS. It talks to the server in `../server`.

## Placeholders to replace before the first store upload

The project name `market` and the organisation `ng.market` are placeholders
until the product is named. They produced the Android `applicationId`
(`ng.market.market`, in `android/app/build.gradle.kts`) and the iOS bundle id
(`ng.market.market`, in `ios/Runner.xcodeproj/project.pbxproj`).

**Set both to their final values before the first store upload.** Neither can
be changed after the app has been published.

## Platform floors

- Android `minSdk` 26
- iOS deployment target 15.0

## Working on it

Install the stable Flutter SDK, then, from this folder:

```
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter analyze
flutter test
```

Files ending `.g.dart` are generated by `build_runner` and are not committed.
